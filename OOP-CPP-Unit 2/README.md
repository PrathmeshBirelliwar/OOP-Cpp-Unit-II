## About This Repository

This repository contains the C++ programming activities and programs completed for **Unit II of Object Oriented Programming using C++**.

The programs demonstrate important Object-Oriented Programming concepts such as inheritance, polymorphism, abstraction, virtual functions, constructors, destructors, friend classes, nested classes, and virtual inheritance.
