# Unit I – C++ Programming Fundamentals

## Description

This repository contains the C++ programming programs for **Unit I** of the Object-Oriented Programming with C++ course.

The programs cover fundamental C++ programming concepts, starting from basic data types and control structures and progressing to classes, objects, constructors, destructors, static members, inline functions, and friend functions.

---

# List of Programs

## Program 01 – Basic Data Types

Demonstrates the use of basic C++ data types such as `int`, `char`, and `float` to store and display student details including roll number, grade, and fee amount.

**Concept Used:** Basic Data Types

---

## Program 02 – if-else

Checks whether a student has passed or failed based on the marks obtained using an `if-else` statement.

**Concept Used:** Selection / if-else

---

## Program 03 – Loop and Array

Stores the marks of five students in an array and displays the marks using a `for` loop.

**Concept Used:** Array and Loop

---

## Program 04 – Functions

Demonstrates the creation and use of an addition function that accepts two integers and returns their sum.

**Concept Used:** Functions / Function Prototype

---

## Program 05 – Class and Object

Demonstrates the creation of a `Student` class and an object to store and display student details.

**Concept Used:** Class and Object

---

## Program 06 – Constructor and Destructor

Demonstrates automatic object initialization using a constructor and object cleanup using a destructor.

**Concept Used:** Constructor and Destructor

---

## Program 07 – Static Member

Demonstrates the use of a static data member to count the number of objects created from the `Student` class.

**Concept Used:** Static Data Member

---

## Program 08 – Inline and Friend Function

Demonstrates an inline member function for accessing a value and a friend function for accessing private data of a class.

**Concept Used:** Inline Function and Friend Function
